# IG — Send this to

Type-only 1080×1350 feed post, built to be forwarded. Sends are one of the biggest reach drivers on IG, and this format asks for one in the first three words. Started from Korian's drafts (Slack, Oct 6) and Travis's notes on them.

## Anatomy
1. **Hook.** Instrument Serif 400, 124px, line-height 0.94, tracking -0.028em, centered, balanced. Always opens "send this to whoever…" or "send this to the person who…", then names a specific food habit and its contradiction.
2. **Rule.** 120×2px hairline, 22–30% opacity.
3. **Payoff.** Instrument Serif italic, 54px. One line that lands the joke. Where it can, point at the food that's already in the fridge, which is what iEatz does.
4. **Wordmark + tagline.** "iEatz", Inter Tight 700, 46px, with "FRIDGE TO TABLE" below it (Inter Tight 500, 20px, uppercase, 0.18em tracking, payoff color), stacked bottom-center at 84px.

## Themes (alternate post to post)
- **Cream:** bg `#F5F2EA`, hook `#0E4A2A`, payoff `#5C625E`
- **Dark green:** bg `#0E4A2A`, hook `#F5F2EA`, payoff `#BBE3C8`

## Copy rules
- Lowercase except proper nouns (Trader Joe’s, DoorDash, Sunday). This series is the exception to the sentence-case headline rule.
- Specific beats general: a real store, a real price, a real day of the week.
- Fresh or refrigerated food only. If it can't go bad, the joke doesn't land.
- Keep hooks under about 80 characters so they fit at 124px. If one runs long, cut words before shrinking the type.
- No photos, no emoji, no CTA button.

## Using it
Duplicate a frame in `IgSendThis.dc.html`, edit the two lines, update the status chip, and export the 1080×1350 frame (`data-screen-label` names each one). Frames preview at 42% (`zoom:0.42` on each wrapper). Tweak: `showGuides`, which shows the 80px safe zone and the bottom 15% caption band.
